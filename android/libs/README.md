# Android runtime (customer install)

Place **`facerecognitionsdk.aar`** here after installing `face-recognition-capacitor`:

```text
node_modules/face-recognition-capacitor/android/libs/facerecognitionsdk.aar
```

Download from the [FacePlugin Android Drive folder](https://drive.google.com/drive/folders/1kpzYVv9Gbm_pEpDe9-x7FGB4NWZzvez0) (same file as FaceRecognitionSDK-Android-App / Flutter / React Native).

Do not commit the AAR.
